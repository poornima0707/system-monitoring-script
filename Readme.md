# System Monitoring Script (DevOps Capstone)

## Project Description
This project is a Linux-based system monitoring tool built using shell scripting. It monitors system resources and generates alerts when thresholds are crossed.

## Features
- Disk usage monitoring
- Memory usage monitoring
- CPU process monitoring
- Memory process monitoring
- Alert logging system

## How to Run
```bash
chmod +x system_monitor.sh
./system_monitor.sh
